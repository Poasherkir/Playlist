# YouTube Playlist Downloader

Download any YouTube playlist with two double-clicks. No technical knowledge needed.

---

## How to Use

### Step 1 — Setup (first time only)
Double-click **`setup.bat`**

It will automatically install everything needed. Takes 1–2 minutes.

### Step 2 — Download
Double-click **`start.bat`**

The program will ask you:
1. The YouTube playlist link
2. Where to save the files (or just press Enter for the default folder)
3. Format: MP4 (video) or MP3 (audio only)

Then it downloads everything automatically.

---

## Output

Files are saved and numbered in order:
```
downloads/
  01 - Video Title.mp4
  02 - Another Video.mp4
  ...
```

---

## Notes

- Private or deleted videos are automatically skipped
- If a download is interrupted, it resumes from where it stopped
- Tested on Windows 10 and Windows 11
