# YouTube Playlist Downloader

Download any YouTube playlist in two clicks. No installation knowledge needed.

---

## First time only

Double-click **`setup.bat`**

It downloads everything automatically. Takes about a minute.

---

## Every time you want to download

Double-click **`start.bat`**

It will ask you:
1. The YouTube playlist link
2. Where to save the files (just press Enter for the default)
3. MP4 (video) or MP3 (audio only)

Then it downloads the whole playlist automatically.

---

## Requirements

- Windows 10 or 11
- Internet connection

That's it.
